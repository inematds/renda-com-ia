Em resumo

Você já conhece problemas, clientes e decisões que uma ferramenta sozinha não entende. Renda com IA é um kit gratuito para transformar essa experiência no desenho de uma operação apoiada por agentes. Você vê uma possibilidade concreta, distribui os papéis, prepara uma demonstração e organiza uma oferta. O kit também ajuda a reconhecer o que pode continuar seu: método, repertório, reputação e autonomia. Os documentos funcionam em um editor; um gerador local opcional monta seu mapa em uma página.

Sua operação em uma página

O gerador opcional transforma o mapa em um documento com resultado, papéis, revisão humana, demonstração, oferta e próximo movimento. Usa Python 3, sem dependências extras, sem rede e sem API.

Comece pelo exemplo pronto

Abra o terminal na pasta extraída renda-com-ia. No Linux ou Mac com Python 3 instalado:

python3 scripts/montar_operacao.py kit/operacao-exemplo.json --saida exemplo-operacao.md

No Windows com Python 3 instalado pelo site oficial python.org, abra a pasta no Explorador, digite cmd na barra de endereço e rode:

py -3 scripts/montar_operacao.py kit/operacao-exemplo.json --saida exemplo-operacao.md

Abra exemplo-operacao.md no editor. Você verá o mapa de uma operação fictícia de manutenção, já organizado para revisar.

Agora, desenhe a sua

Copie kit/operacao-modelo.json como kit/minha-operacao.json. Preencha os valores sem alterar as chaves, descreva a aprovação humana e escolha outro nome de saída:

python3 scripts/montar_operacao.py kit/minha-operacao.json --saida minha-operacao.md

No Windows, use py -3 no lugar de python3. O programa avisa se faltam campos ou se o arquivo de saída já existe. Para substituir um arquivo seu deliberadamente, acrescente --sobrescrever. Saída 0 indica documento gerado; saída 2 indica erro de preenchimento ou arquivo.

Conferência anterior do CSV de investigação

O conferidor do material de apoio continua funcionando. Ele verifica preenchimento, não demanda, renda ou verdade das evidências:

python3 scripts/conferir.py kit/exemplo.csv

O exemplo retorna os IDs agentes e midia com 6/6 campos. No Windows, use py -3. O gerador novo usa JSON; este conferidor usa CSV.

Os arquivos do kit estão em português. O guia tem versões em inglês e espanhol. O mapa gerado é um plano, não uma automação instalada.
