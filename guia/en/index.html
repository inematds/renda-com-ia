In short

You already know problems, clients, and decisions that a tool alone can’t understand. Renda com IA is a free kit to turn that experience into a design for an operation supported by agents. You identify a concrete possibility, assign roles, prepare a demonstration, and organize an offer. The kit also helps you recognize what can remain yours: methods, expertise, reputation, and autonomy. The documents work in an editor; an optional local generator builds your map on a page.

Your operation on one page

The optional generator turns the map into a document with the result, roles, human review, demo, offering, and next step. It uses Python 3, with no extra dependencies, network access, or API.

Start with the ready-made example

Open the terminal in the extracted folder renda-com-ia. On Linux or Mac with Python 3 installed:

python3 scripts/montar_operacao.py kit/operacao-exemplo.json --saida exemplo-operacao.md

On Windows with Python 3 installed from the official python.org website, open the folder in File Explorer, type cmd in the address bar and run:

py -3 scripts/montar_operacao.py kit/operacao-exemplo.json --saida exemplo-operacao.md

Open exemplo-operacao.md in the editor. You’ll see a fictional maintenance operation map, already organized for review.

Now, design yours

Copy kit/operacao-modelo.json such as kit/minha-operacao.json. Fill in the values without changing the keys, describe the human approval, and choose another output name:

python3 scripts/montar_operacao.py kit/minha-operacao.json --saida minha-operacao.md

On Windows, use py -3 instead of python3. The program warns you if fields are missing or the output file already exists. To deliberately replace one of your files, add --sobrescrever. Exit code 0 means the document was generated; exit code 2 means a data entry or file error.

Previous validation of the investigation CSV

The support material checker still works. It checks completion, not demand, income, or the truth of the evidence:

python3 scripts/conferir.py kit/exemplo.csv

The example returns the IDs agentes e midia with 6/6 fields. On Windows, use py -3. The new generator uses JSON; this validator uses CSV.

The kit files are in Portuguese. The guide has English and Spanish versions. The generated map is a plan, not an installed automation.
